# Compare interferometer arrays

This task documents the spatial-frequency coverage and image consistency of
the ACA 7 m and ALMA 12 m continuum observations.

## Inputs

The four measurement sets under
`data/reduction/alma/7MTM2TM1/cont/ms/` are declared read-only intermediate
inputs. The task reads only their `UVW` columns and never modifies reduction
data.

Image inputs are the float32 MJy/sr products generated by
`prepare_continuum_images`. The DS9 region marking successful image
combinations is a read-only project input.

## Stages

- `inspect` reports dependency readiness without writing files.
- `uv` reads and deduplicates UV coordinates in bounded row chunks, caches
  compact coordinate arrays, and creates the composed manuscript figure.
- `compare-images` creates the vertical ACA, 12 m, and 12 m plus 7 m
  manuscript comparison.
- `beam-match` convolves the combined interferometer image to the ACA beam,
  reprojects it to the ACA grid, writes a float32 FITS map and residual map,
  records residual statistics, and creates a diagnostic PNG.
- `all` runs all stages in dependency order.

All generated products are written under
`results/compare_interferometer_arrays/`.

Run:

```bash
conda run -n py312 python scripts/compare_interferometer_arrays.py --stage inspect
conda run -n py312 python scripts/compare_interferometer_arrays.py --stage uv
conda run -n py312 python scripts/compare_interferometer_arrays.py --stage compare-images
conda run -n py312 python scripts/compare_interferometer_arrays.py --stage beam-match
```

UV plotting reuses the cached coordinate arrays by default. Add
`--refresh-uv` only when the measurement sets themselves have changed.
